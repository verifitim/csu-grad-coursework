# Team 4 — Job Posting (US14)

Fictional hiring-manager prototype. Single HTML file, browser-local interactions, no backend or real posting publication.

Based on Part 1: hiring managers define required and preferred qualifications and choose traditional qualification screening, skills matching, or both. The interface keeps requirements applicable across all evaluation choices and allows equivalent experience to be explicitly described.

Includes job details, editable required/preferred qualifications, movement between buckets, evaluation approach selection, posting preview, and local saving. Scoring weights, screening-question approval (US1), real applicant evaluation, and real job publication are outside this page.

Validation: JavaScript syntax and unique HTML IDs checked. Browser execution remains unavailable, so visual and end-to-end browser checks have not been performed.
